[`historical-audit-report.json`](historical-audit-report.json), generated by
[`scripts/historical_evaluation_audit.py`](../../scripts/historical_evaluation_audit.py).
The audit does not rewrite history, recompute a historical verdict, or create
Host Acceptance evidence.

  recomputable current rubric score and an independent review of preserved
