`Reviewer decision` is the independent reviewer's judgment on this run and is
one of `accept`, `accept-with-residuals`, `reject`, or `not-reviewed`. The
`Reviewer` MUST differ from the trace author. `Unverified limitations` names
what this run did not establish; it is not a list of minor defects. A single
scored run is evidence about one run, not a host compatibility claim.


New scored packages must satisfy the [evidence integrity contract](../../docs/evaluation-evidence-integrity.md).
Every numeric dimension needs a real event reference and must be bound by an
approved review receipt. An operator-approved index is not generated by this template.
Blank template rows are not scores or evidence. B7 critical rows are validated,
not merely displayed; runtime behavior remains unverified until actually observed.

`Limitation state` and `Unverified limitations` project the same approved
version-2 review receipt. Use `unverified`, `unresolved`, or `resolved` explicitly;
do not replace an unresolved receipt with a resolved prose claim. See the
[evidence integrity contract](../../docs/evaluation-evidence-integrity.md).
